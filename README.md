## Sobre o Projeto

**Pokémon Personality** é um projeto desenvolvido em Python para criar um teste de personalidade baseado no modelo OCEAN, relacionando as características identificadas no usuário aos perfis de diferentes Pokémons.

O projeto utiliza cinco atributos de personalidade — Abertura, Consciência, Expressividade, Sociabilidade e Sensibilidade — como referência para a construção dos perfis.

As características dos Pokémons são definidas com base em informações de lore e entradas da Pokédex, buscando representar suas características de personalidade dentro do universo da franquia.

O projeto foi desenvolvido com finalidade educacional e de portfólio, visando praticar programação em Python, estruturas de dados, lógica de programação e organização de projetos.

---

## Funcionalidades

- Identificação de características de personalidade através de perguntas.
- Construção de perfis de personalidade para usuários e Pokémons.
- Associação entre características de personalidade e diferentes Pokémons.
- Comparação entre o perfil do usuário e os perfis dos Pokémons.
